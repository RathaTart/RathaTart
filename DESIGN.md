# Profile design

Original SVG artwork and a navy/mint palette, built specifically for Ratha Rotruchiphong. All visual assets are stored in this repository; the profile does not depend on third-party stats or badge servers.

## Inspiration

- [Braydon Coyer](https://github.com/braydoncoyer/braydoncoyer): banner-led introduction and featured-project presentation.
- [Anurag Hazra](https://github.com/anuraghazra/anuraghazra): a compact personal introduction and clear technology cues.
- [Sindre Sorhus](https://github.com/sindresorhus/sindresorhus): a distinctive personal visual identity.

These were layout references. No artwork, biography, code, or achievement claims were copied.

## Maintenance

- Edit the professional summary, experience, and education in `README.md` as they change.
- Keep team-project credits and individual contribution descriptions accurate.
- Edit `assets/header.svg` for the banner; run `python assets/generate.py` to regenerate project cards and the technology strip.
- Keep essential information in ordinary README text and provide descriptive alt text for images.
- Career and education details were supplied through the owner's CV in September 2026. The original CV is not included in this repository.

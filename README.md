# Hi, I'm RathaTart

### Backend APIs · Web applications · Team projects

My portfolio brings together a food-sharing backend, an event web application, and interactive web projects. My documented team experience includes backend development on **Togeta**, a KMITL Web Application Development project.

For a quick introduction to my work, start with **FoodBridge** for backend architecture, **Togeta** for team-based web development, and **DrugBrief** for AI integration.

## Selected projects

| Project | What it does | Technologies and context |

| [FoodBridge](https://github.com/RathaTart/FoodBridge) | Backend for sharing free meals, with accounts, food posts, bookings, and notifications. | Go, Echo, GORM, PostgreSQL, Docker. Explore its API routes and controller/service/repository structure. |
